## 7. Release notes summary

Title: **Market Sentinel v0.6.0 — Feedback, Observability & Offline Tuning**

See `CHANGELOG.md` `## 0.6.0`. Added: structured telemetry, local JSONL, evaluation report, optional explicit feedback, offline tuning snapshots/comparison. Safety: no online self-modification, no automatic promotion, no trading advice, no workspace/conversation collection, Protocol v1 maintained. Supported offline parameters are exactly the seven with Consumed + Observable + Sensitivity proof. Candidate snapshot ≠ production config.

## 8. Privacy audit

Artifacts (`telemetry.jsonl`, `feedback.jsonl`, tuning snapshots, comparison reports, Protocol `user_feedback` / `host_interaction`) use allowlists. Denied / not stored: workspace, conversation, source code, file contents, absolute user fixture paths, raw ticks copied into reports, features payload, prompt, API key, model raw output, Signal title/summary, free-text feedback, free-form tuning notes.

Allowed: fixed config fields, snapshot identity, corpus IDs, aggregated metrics, fixed feedback labels/counts, fixed data-quality counters.

## 9. Local-data layout

```text
MarketSentinel data directory/
├ telemetry.jsonl
├ telemetry.jsonl.1 ...
├ feedback.jsonl
├ feedback.jsonl.1 ...
└ tuning/
   └ <snapshot_uuid>.json
```

Override: `MARKET_SENTINEL_DATA_DIR`. Otherwise Windows `%LOCALAPPDATA%/MarketSentinel` or Unix XDG `market-sentinel`. No user-specific absolute paths in docs. Host does not write these files. Core / local CLI own storage. Telemetry/feedback are append-only. Tuning snapshots are immutable and not auto-loaded.

## 10. Backward compatibility

- Protocol v1 additive. Omitting `host_interaction` / `user_feedback` does not change the old path.
- New local files do not change MarketState / Event / Signal wire semantics.
- Draft tuning artifact schema 1 was never a released v0.6 artifact. `load_snapshot()` fail-closes. No migration.

## 11. Known limitations

- A-share `.SH`/`.SZ` market-hour metric; weekends excluded; no full exchange holiday calendar; HK market-hour is unavailable, not an A-share window.
- Host `signal_opened` / `alert_dismissed` / `signal_muted` producers are unimplemented (rates unavailable, not 0%).
- JSONL writes stay synchronous (`write` → `flush` → `stat` → possible rotate). v0.6 does not switch to async.
- `ClusterMembershipTracker` retains clustered event ids for the run (theoretically unbounded within a run).
- Tuning Replay is monotonic-frozen, so cooldown/dwell stay deferred. Comparator does not attach Intelligence, so Router/budget stay deferred. Event module-global thresholds/TTL stay deferred.
- Explicit feedback samples have self-selection bias.
- Trusted local Protocol may store structurally valid unknown `signal_id`; M5/M6 tuning datasets join telemetry and drop orphans.
