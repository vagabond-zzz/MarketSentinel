## 2. How to run probes

Default tests stay offline:

```bash
uv run pytest
```

Live marker is excluded by default (`addopts = -m "not live"`).

```bash
# Experimental Tencent HTTP (stdlib urllib; no extra deps)
uv run python -m tools.live_probe tencent --symbols 600519.SH,000001.SZ --interval 2 --count 30 --out .tmp/tencent.jsonl

# Official Longbridge SDK (optional extra; env credentials)
uv sync --extra live
uv run python -m tools.live_probe longbridge --symbols 600519.SH,000001.SZ --interval 2 --count 30 --out .tmp/longbridge.jsonl

# Classify a local JSONL (gitignored)
uv run python -m tools.live_probe analyze --in .tmp/tencent.jsonl
```

Interval **cannot** be below 2s. Credentials are never printed. `.tmp/` is gitignored. Do not commit live ticks.

## 19. Ranking (criteria required)

1. **MarketSnapshot semantic correctness** — Longbridge still the only source with official snapshot field names. Tencent indexes are INFERRED. **Incomplete live proof on Longbridge.**
2. **Volume cumulative reliability** — Tencent idle-only LIKELY; Longbridge PENDING. **Neither CONFIRMED.**
3. **Market timestamp reliability** — Tencent VALID vs receive clock (frozen). Longbridge documented, live PENDING.
4. **Turnover/volume commensurability** — Tencent UNIT_MISMATCH_LIKELY on raw fields. Longbridge PENDING.
5. **A-share freshness** — Tencent post-close ~45 min lag vs last stamp. Longbridge PENDING.
6. **Failure behavior** — both probes fail closed in unit tests; Tencent live happy-path only.
7. **Rate-limit confidence** — Longbridge HIGH (docs). Tencent UNKNOWN.
8. **Testability** — Tencent easier (HTTP fixtures). Longbridge SDK mockable at `quote_fn`.
9. **Credential friction** — Tencent none; Longbridge three env vars (blocked this run).
10. **Contract/licensing stability** — Longbridge official non-commercial API. Tencent UNKNOWN → cannot be supported.
11. **Implementation complexity** — Tencent HTTP is simpler; **must not outrank (1)(10).**

Free/no-login does **not** win. Official SDK does **not** automatically win until live A-share semantics are measured.
