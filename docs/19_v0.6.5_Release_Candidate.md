## 5. Intelligence switch semantics

Priority: explicit CLI `--intelligence` / `--no-intelligence` > `MARKET_SENTINEL_INTEL_ENABLED` > Core default off.

Cursor setting:

| Setting | Spawn |
|---|---|
| `on` | `--intelligence` |
| `off` | `--no-intelligence` |
| `inherit` (default) | omit flag |

Hover AI line uses requested setting vs actual wire `intelligence_enabled`:

| Requested | Actual | Label |
|---|---|---|
| `off` | enabled | `待重启（当前仍启用）` |
| `on` | disabled, restart pending | `待重启` |
| `on` | disabled, not pending | `不可用（Rule-only）` |
| `off` | disabled | `关闭` |

API keys stay environment-only (`DASHSCOPE_API_KEY`). The setting is a switch, not a secret store. Live DashScope is **not** a default release gate.

## 6. StatusBar / Hover

Priority after host lifecycle: real feed STALE/DISCONNECTED → ALERT hold (15s) → `replay_complete` → DELAYED → HOT/WARM/NORMAL.

No-signal Hover is a compact snapshot (`price · day · level` plus metrics), not a blank diagnostic dump.

`last_market_timestamp` is labeled `最后行情：HH:MM:SS（UTC+8）`. Aliases are sanitized on StatusBar/QuickPick; Hover still `escapeMarkdown()`. Canonical symbol identity does not include aliases.

## 7. Watchlist commands

Command Palette: Add Symbol, Remove Symbol, Manage Watchlist.

- Persist `{symbol, enabled}` to Workspace `marketSentinel.watchlist`
- Runtime `syncWatchlist()` (`lastAcked` / in-flight target / in-flight promise); no Restart Core required for a successful runtime update
- Disabled items are not re-enabled
- CLI `data/watchlist.json` is a separate entry point; not bi-directionally synced

## 8. Replay EOF semantics

`source_exhausted()` is checked **before** `fetch_quotes()`. Only an already-exhausted source may `keep_alive` without a missing-quote observation.

`keep_alive` updates `last_success_mono` only when `consecutive_failures == 0`. A real last-batch missing symbol stays on the missing-quote path; the next fetch is graceful EOF.

If the last tick presented an Alert: StatusBar keeps ALERT hold for 15s, then Replay 已结束. Last price / state / Signal are retained. Live provider missing-quote behavior is unchanged.

## 9. `alert_presented` lifecycle

Queued jobs capture origin IPC, origin manager generation, and `created_timestamp` at Host presentation.

- connected / graceful teardown: await presentation queue
- abrupt Core loss: best-effort
- never cross-run misattribute

Unread Host badge and persisted telemetry are not claimed to match after a hard Core crash.
