## 12. Duplicate / out-of-order

- Older `market_timestamp`: **suppress** (no buffer append, no Feature/Event). Increment `out_of_order_count`. Treat as a **failed observation** (`health.observe(symbol, error=...)`) so `last_success_mono` is not refreshed. Repeated old quotes can reach STALE / DISCONNECTED under existing `HealthPolicy` (`delayed_s=3`, `stale_s=30`, `disconnect_s=60`, `disconnect_failures=3`).
- Duplicate timestamp: RingBuffer **replace**; engine counts `duplicate_timestamp_count`; cooldown/dedupe still apply (no manufactured extra alert edge).
