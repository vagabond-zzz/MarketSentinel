## 7. Production Provider architecture

```text
CLI/Host --provider longbridge
  → LongbridgeQuoteProvider
       quote_fn seam / SDK QuoteContext.quote (one batch)
       vendor DTO extract
       SH/SZ filter
       fail-closed map (turnover omitted)
  → normalize_snapshot(clock)   # received_timestamp from Clock
  → MarketEngine ingest
       older market_ts suppressed
       duplicate ts replaced
  → Feature / Event / Signal (unchanged math)
  → Protocol v1 state/alert
```
