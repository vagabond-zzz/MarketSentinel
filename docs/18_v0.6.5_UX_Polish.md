# Market Sentinel v0.6.5 — UX polish (implementation record)

Package remains **0.6.0**. Protocol remains **1**. Branch: `feat/v0.6.5-ux-polish`.

This is Host / CLI usability polish. Market semantics are unchanged. No version bump, merge, tag, or push until external review.

## U0 audit

1. Current price is already on `WireSymbolState.price`.
2. Day change exists on Domain (`MarketFeatures.change_day` from `prev_close`) but was missing on Wire/Host.
3. Additive optional `change_day` (and session high/low refs) were added. UI never labels 1m/5m as 当日涨跌幅.
4. Intelligence summary is `WireSignal.intelligence.summary` when `status === "enriched"`.
5. Host aggregate feed is Core `FeedHealthTracker.aggregate_status` → `WireMarketState.feed_status`.
6. Replay EOF previously returned `[]`, which Engine treated as `missing quote` and aged into STALE. Replay now exposes `source_exhausted()`; Engine `keep_alive`s last health and sets optional `replay_complete`.

## Additive Protocol v1 fields

Optional on `WireMarketState`: `intelligence_enabled`, `replay_complete`, `last_market_timestamp`.

Optional on `WireSymbolState`: `change_day`, `above_vwap`, `session_high_obs`, `session_low_obs`, `session_high_ref`, `session_low_ref`, `market_timestamp`.

Old clients omitting these fields still parse.

## Two watchlist entry points

- CLI: `data/watchlist.json`
- Cursor: Workspace `marketSentinel.watchlist` via settings or Add/Remove/Manage commands

They are not bi-directionally synced. Host persist writes `{symbol, enabled}` objects so disabled items stay disabled.

## Intelligence

Priority: explicit CLI `--intelligence` / `--no-intelligence` > `MARKET_SENTINEL_INTEL_ENABLED` > Core default off.

Cursor `marketSentinel.intelligence`: `on` / `off` / `inherit` (default `inherit`). `on` → `--intelligence`; `off` → `--no-intelligence`; `inherit` omits the CLI flag. API keys remain environment-only.

Hover AI line combines the Host setting, `restartNeeded`, and Core `intelligence_enabled`. Explicit `on` with fail-open / missing key shows `不可用（Rule-only）` or `待重启`, not `关闭`.

## Replay StatusBar vs last alert

Priority after host lifecycle: real feed STALE/DISCONNECTED → ALERT hold (15s) → `replay_complete` → DELAYED → HOT/WARM/NORMAL.

Hover may show `模式：Replay` / `状态：已播放完成` during the alert hold.

## Replay EOF vs missing quote

`source_exhausted()` is checked **before** `fetch_quotes()`. Only a source that was already exhausted may `keep_alive` without a missing-quote observation. Consuming a real last batch that does not contain the requested symbol keeps the missing-quote path. The next fetch is graceful EOF.

`keep_alive` updates `last_success_mono` and does **not** reset `consecutive_failures`.

## alert_presented

Queued jobs capture origin IPC, origin manager generation, and `created_timestamp` at Host presentation (unread increment). Flush uses only origin IPC.

- connected / graceful teardown: await presentation queue
- abrupt Core loss: best-effort
- never cross-run misattribute

Unread Host badge and persisted telemetry are not claimed to match after a hard Core crash.

## Watchlist commands

`commitWatchlist` and `applyWatchlistHotUpdate` skip `set_watchlist` when desired equals acknowledged. If settings persist succeeded and runtime update failed, the Host says the watchlist was saved and the runtime update will apply after reconnect/restart.

## Display

StatusBar / QuickPick aliases: collapse CR/LF/tab, neutralize `$(...)`, replace `|`, cap length. Canonical symbol identity is unchanged. Hover still uses `escapeMarkdown()`.

`last_market_timestamp` is shown as `最后行情：HH:MM:SS（UTC+8）`. `signal.family` is labeled `信号类型` (Protocol v1 has no event-rule list).
