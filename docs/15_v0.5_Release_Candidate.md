`MarketEngine.tick()` never `await`s the model.

## 6. Router rules

Skip (no call): expired episode; cooldown/duplicate edge (`alert_edge=False`); STALE/DISCONNECTED; missing `change_1m`+`change_5m`+`volume_ratio_5m`; INFO; ordinary NOTICE; episode budget exhausted.

Candidate: priority IMPORTANT or CRITICAL; or price+volume+breakout cluster (or ≥3 event types with price and volume).

DELAYED feed may still be a candidate. Policy is `RouterPolicy`, not the model.

## 7. Episode call budget

`EpisodeCallBudget(max_calls=1, allow_escalation_recall=False)`.

A later CRITICAL upgrade does **not** get a second call unless `allow_escalation_recall=True`.

Budget is consumed when work is **queued**, so repeats of the same `signal.id` do not enqueue again.

## 8. Async / queue / cancellation

- `asyncio.Queue(maxsize=8)`, concurrency 1
- `put_nowait`; full queue drops work (`dropped_backpressure`) and does not block tick
- `asyncio.wait_for(..., timeout_s)` around `provider.complete`
- Stale generation discarded
- `shutdown()` cancels workers; daemon `run()` starts/stops the sidecar
- Default daemon does not construct a coordinator unless `MARKET_SENTINEL_INTEL_ENABLED` is set

## 9. Fallback matrix

| Failure | `FallbackReason` | Rule Signal |
|---|---|---|

| malformed JSON / trading-advice text | `malformed` | kept |
| HTTP 429 | `rate_limited` | kept |
| transport / unavailable / auth | `unavailable` / `transport` | kept |
| not a candidate / stale / budget | skip, no call | kept |

Host does not show fallback error copy. Original title/summary remain.

## 10. Protocol v1 additive changes

`PROTOCOL_VERSION` remains **1**.

`WireSignal` may include optional `intelligence`:

```text
status: queued | running | enriched | fallback
summary?, reason?, confidence?, fallback_reason?, worth_highlight?
```

Omitted when `not_requested`. Old fixtures without the field still parse.

`WireAlertCandidate` is unchanged (no extra toast).

## 11. Cursor presentation

Rule title/summary always shown. Enrichment line only if `status === "enriched"` and summary is non-empty. Fallback: original Rule Signal only. Hover/click/toast do not call a model or re-run the router.

## 12. Privacy / secrets

Model payload allowlist: `signal_id, symbol, family, direction, priority, event_types, change_1m, change_5m, volume_ratio_5m, above_vwap, rsi14, day_range_position`.

Never sent: RingBuffer, ticks, `SignalTrace`, workspace, Cursor conversation, `DASHSCOPE_API_KEY`.

Key from env `DASHSCOPE_API_KEY` only. Redacted as `[redacted]` if it appears in adapter error text. Not in Protocol, argv, or git.

Enable:

```text
MARKET_SENTINEL_INTEL_ENABLED=1
MARKET_SENTINEL_INTEL_PROVIDER=dashscope   # or fake
MARKET_SENTINEL_INTEL_MODEL=qwen3.7-max-2026-06-08   # optional override
DASHSCOPE_API_KEY=...
```
